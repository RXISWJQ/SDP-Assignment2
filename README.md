# Assignment 2: Factory Method & Abstract Factory

**Course:** SDP  
**Domain Selected:** Minecraft World Generation Kit  

## Selected Domain Overview
This repository implements two creational design patterns applied to the Minecraft game domain:
- **Part A (Factory Method):** Manages the spawning of individual Minecraft mob entities (`Zombie`, `Skeleton`, `Creeper`).
- **Part B (Abstract Factory):** Generates consistent Minecraft biome environments consisting of a matching set of `Enemy`, `Terrain`, and `Soundtrack` (e.g., Overworld vs. Nether).

## Repository Structure
- `src/factorymethod/` - Implementation of Factory Method (Part A)
- `src/abstractfactory/` - Implementation of Abstract Factory (Part B)
